# NEXUS brand provenance

## Project provenance

NEXUS is the AI identity and orchestration concept created for **MGP — My Gamer Profile** by the MGP project owner. The concept, product role, naming direction, gamer-facing personality, mother/core architecture and the first N/Z interface-mark direction were established as part of the MGP project on 2026-09-16.

The repository history is intended to preserve technical and creative provenance for the NEXUS implementation, including the source files for its interface mark, runtime, prompts, orchestration rules and product behavior.

## N/Z interface mark

The first NEXUS interface mark is implemented as original vector geometry in:

`src/components/nexus/NexusMark.tsx`

Its direction is an angular **N** whose silhouette also suggests a **Z**, with pointed terminals. It is intentionally stored as editable vector code rather than a third-party logo asset.

## Ownership records and personal data

This repository must **not** store the owner's CPF, private phone number, home address, identity-document numbers, private signatures or other unnecessary legal identifiers.

If the owner wants NEXUS registrations, contracts, trademark filings, copyright evidence, company records or other legal documentation tied to their legal identity, those records should be maintained in a private legal/business record system outside the public/client application source tree.

Contact information exposed publicly by MGP should use a dedicated business/contact channel whenever possible rather than personal identifiers.
