# VALORANT competitive sources

For the v0.1.9 competitive compendium:

- VLR.gg is the secondary competitive reference for teams, rosters, events, schedules and match context.
- ProSettings.net is the secondary reference for professional player settings and gear.
- Official Riot / VALORANT Esports sources remain preferred whenever they directly cover the same factual claim.
- MGP stores a verification date and source URL with curated snapshots.
- Rapidly changing settings must not be guessed. If a player's settings have not been individually verified, the UI links to the live ProSettings VALORANT directory instead.
- Do not copy site branding or media unless reuse rights are separately established.
