# VALORANT competitive sources

For the v0.1.9+ competitive compendium:

## Tier-1 scope

- The curated Tier-1 directory covers every organization that participated in the four VCT 2026 Stage 2 regional leagues: Americas, EMEA, Pacific and China.
- VLR.gg event pages establish VCT Stage 2 participation. Individual VLR.gg team pages are the secondary reference for the latest roster state, player handles and real names when available.
- Rosters are a dated snapshot (`verifiedAt`) and may differ from the historical five that played an earlier tournament because transfers, loans, stand-ins, inactive players and substitutes change over time.
- Roster status is preserved when the source distinguishes an active player, substitute, inactive player, stand-in or loan.

## Player settings and gear

- ProSettings.net is the secondary reference for professional player settings and gear.
- Settings are copied into MGP only after the individual player's page has been checked. DPI, sensitivity, eDPI, polling rate, mouse, resolution and crosshair must not be inferred from teammates or old social posts.
- If a player's settings have not been individually verified, the UI keeps those values hidden instead of guessing.
- Fast-changing settings retain a verification date and a direct source URL.

## Source priority

- Official Riot / VALORANT Esports sources remain preferred whenever they directly cover the same factual claim.
- VLR.gg is used for competitive roster/event context where an equivalent structured official source is not available to MGP.
- ProSettings.net is used for player peripherals/settings snapshots and is not treated as an official Riot source.

## Media / ATLAS gate

- Public accessibility does not automatically grant MGP permission to copy, re-host or commercially reuse a player photo, team logo or other media.
- Existing approved/provenance-tracked remote assets may continue to be used, but new media must pass the ATLAS rights/provenance check first.
- When rights are unclear, use the MGP initials/avatar fallback and keep a contextual source link rather than copying the image.
- Do not copy third-party site branding.
